## Chandrayaan Landing Simulation (MATLAB)

This project presents a MATLAB-based simulation of a lunar landing inspired by Chandrayaan-3.

The objective is to model a simplified autonomous landing system using physics-based motion and feedback control.

 
## Key Features

- Simulation under lunar gravity conditions
- Real-time trajectory visualization
- Space-themed environment (stars, planets, terrain)
- Dynamic thrust-based descent
- Landing validation (safe / crash detection)
- MP4 video generation of the landing sequence



## Concepts Used

- Feedback Control Systems (PD Controller)
- Kinematics and Motion Equations
- Numerical Simulation
- Data Visualization in MATLAB

## Output

The simulation generates a landing animation exported as an MP4 file.



## Disclaimer

This is a simplified academic simulation inspired by Chandrayaan-3 and does not represent the full complexity of real-world space missions.
